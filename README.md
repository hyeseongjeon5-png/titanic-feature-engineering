# Titanic Feature Engineering Assignment

## Project Overview
This project compares machine learning performance according to different feature engineering strategies using the Titanic Dataset.

## Dataset
- Dataset: Kaggle Titanic - Machine Learning from Disaster
- File used: train.csv
- Target variable: Survived
- Task type: Binary Classification

## Models
- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Main Result
The best overall performance was achieved by Logistic Regression in Exp-1.

- Accuracy: 0.8268
- F1-score: 0.7559
- ROC-AUC: 0.8594
